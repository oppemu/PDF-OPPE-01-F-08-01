# PDF รวมแบบฟอร์มและหนังสือรายงาน

## อัปโหลดขึ้น GitHub Pages
1. แตก ZIP แล้วอัปโหลดทุกไฟล์และโฟลเดอร์ fonts ไว้ที่เดียวกับ index.html เดิม
2. ใช้ชื่อ index.html, config.js, script.js, style.css, LOGO.png ตามชุดนี้ ไม่ใช้ชื่อที่มี (2) หรือ (3)
3. รอเว็บไซต์อัปเดต แล้วรีเฟรชแบบล้างแคชด้วย Ctrl+Shift+R หรือ Command+Shift+R
4. ค้นหารายการ กดดูตัวอย่าง PDF แล้วดาวน์โหลด PDF เลือก Save as PDF ในหน้าต่างพิมพ์
5. พิมพ์ทุกหน้า สเกล 100% ปิด Headers and footers ของเบราว์เซอร์ แนะนำ Chrome/Edge รุ่นปัจจุบันเพื่อรองรับขนาดหน้าต่างกันในไฟล์เดียว

ชุดนี้เป็นเว็บไซต์ PDF ไม่แก้ข้อมูลในชีต การบันทึกเลขที่หนังสือบริษัทและวันที่บนหนังสือบริษัทต้องใช้ชุดฟอร์ม/Google Apps Script ที่รองรับสองช่องนี้ด้วย และเผยแพร่ Apps Script รุ่นที่แก้แล้ว ส่วน API ของเว็บไซต์ PDF ต้องส่งหัวคอลัมน์ใหม่ใน fullRowData มาให้ครบ

## ชื่อไฟล์ PDF
- ตั้งชื่อแนะนำจากชื่องานของแถวที่เลือก ตัดข้อความส่วนยาวเหลือหัวเรื่องสั้นและต่อรหัสรายการเพื่อแยกไฟล์ เช่น “งานบำรุงรักษาระบบจำหน่ายไฟฟ้า 22 kV_OPPE01F0801-58.pdf”
- รองรับภาษาไทย ไม่ตัดกลางตัวอักษร/วรรณยุกต์ และล้างเครื่องหมายที่ระบบไฟล์ไม่อนุญาต ถ้าชื่องานว่างใช้ “รายงาน” ตามด้วยรหัสรายการ
- ชื่อแสดงในหน้าตัวอย่าง และเป็นชื่อเอกสารของหน้าต่างพิมพ์ก่อนเรียกพิมพ์ โดยไม่เปลี่ยนข้อความในเอกสารหรือชีต
- ระบบยังใช้ Save as PDF ของเบราว์เซอร์ จึงตั้งได้เป็นชื่อแนะนำ ไม่สามารถบังคับชื่อในหน้าบันทึกของทุกเบราว์เซอร์หรือโปรแกรมเครื่องพิมพ์ PDF ได้ หากหน้าบันทึกไม่ใช้ชื่อนี้ สามารถคัดลอกชื่อที่แสดงในตัวอย่างไปใช้ได้

## แก้ไขข้อความก่อนดาวน์โหลด
- ในหน้าตัวอย่าง คลิกข้อความเพื่อพิมพ์ แก้ไข หรือลบได้ทั้งหนังสือรายงานและแบบฟอร์มเดิม รวมส่วนหัว เรื่อง เรียน เนื้อหา ชื่อ/บทบาทผู้ลงนาม หัวข้อ ช่องข้อมูล และข้อความ footer
- บรรทัดเริ่มต้นเป็น “เรียน ประธานกรรมการตรวจรับพัสดุ” โดยไม่ใส่ชื่อบุคคลหรือตำแหน่งด้านล่าง ผู้ใช้เปลี่ยนผู้รับและเพิ่มหลายบรรทัดได้ตามงาน รายชื่อในส่วนลายเซ็นยังอยู่ตามข้อมูลเดิม
- กด “จัดหน้าใหม่” เพื่อตรวจการแบ่งหน้า หรือกด “ดาวน์โหลด PDF” เพื่อพิมพ์ข้อความที่แก้ล่าสุด ระบบไม่ดึงข้อมูลเดิมมาทับข้อความที่แก้
- กด “คืนค่าต้นฉบับ” แล้วตอบยืนยันเพื่อยกเลิกการแก้ของรายการนั้น การแก้ของแต่ละรายการแยกกัน ปิดตัวอย่างแล้วเปิดรายการเดิมในแท็บเดียวกันยังอยู่ แต่รีเฟรชหรือปิดแท็บแล้วจะหาย
- แก้เฉพาะสำเนาในเบราว์เซอร์ ไม่มีการบันทึกกลับ Google Sheet หรืออัปโหลดข้อความที่แก้ไปที่อื่น
- วางข้อความเป็นข้อความธรรมดา เพื่อรักษาฟอนต์และรูปแบบเดิม ช่อง footer อยู่บรรทัดเดียวและแก้พร้อมกันทุกหน้าของเอกสารส่วนนั้น เลขหน้าคงรันอัตโนมัติ ส่วนโลโก้ ขนาดกระดาษ และระยะขอบคงรูปแบบเดิม
- ถ้าข้อความยาวเกินพื้นที่หรือ footer ยาวเกินขอบ จะให้แก้ข้อความก่อนพิมพ์ ไม่ตัดข้อความหรือย่อฟอนต์เอง
- PDF ที่ดาวน์โหลดเป็นเอกสารพิมพ์ ไม่ใช่แบบฟอร์ม PDF ที่มีช่องกรอก การแก้ทำในหน้าตัวอย่างก่อนดาวน์โหลด

## ผลลัพธ์ตามการปรับล่าสุด
- หนังสือรายงานใหม่อยู่ก่อน แล้วต่อแบบฟอร์มเดิมใน PDF เดียว ข้อมูลทั้งสองส่วนมาจากแถวที่เลือก
- สองคอลัมน์ใหม่สำหรับเลขที่หนังสือบริษัทและวันที่บนหนังสือ ใช้ในหนังสือส่วนแรกเท่านั้น ไม่เพิ่มแถวท้ายแบบฟอร์มเก่า ส่วนวันที่บริษัทส่งงานเดิมยังอยู่ในแบบฟอร์มเก่าเหมือนเดิม
- ชื่อหน่วยงานแสดงชื่อเต็มเป็นค่าเริ่มต้นในตัวอย่างและ PDF ทั้งสองส่วน แต่ชีตยังเก็บรหัสเดิม
- เฉพาะหนังสือใหม่ใช้ฟอนต์ TH Sarabun New จริง ขนาด 15 pt โดยมีไฟล์ฟอนต์ในชุดและรอโหลดก่อนพิมพ์ แบบฟอร์มเดิมคงฟอนต์ ขนาดตัวอักษร และข้อมูลเดิม ปรับชื่อหน่วยงานเป็นชื่อเต็ม ขอบกระดาษ และ footer ตามที่อนุญาต
- ทุกหน้าใน PDF รวมแบบฟอร์มเดิม: ระยะขอบเนื้อหาซ้าย 3 ซม. ขวา 2 ซม. บน 2 ซม. ล่าง 0.5 ซม. ตามคำขอล่าสุด ปรับการแบ่งหน้าให้เข้ากับขอบใหม่โดยไม่ตัดข้อมูล
- ส่วนงานผู้สร้างทางขวาเลื่อนขึ้น 1 บรรทัด (20 pt) จากรุ่นก่อน โดยโลโก้อยู่เดิม เว้นหนึ่งบรรทัดหลังโทรศัพท์ก่อน “ที่” และหลัง “เรื่อง” ก่อน “เรียน”; “ที่ / วันที่ / เรื่อง” เรียงคนละบรรทัดต่อกัน ไม่ซ้อนกับส่วนงาน
- โลโก้รักษาสัดส่วนเดิม ทั้งความกว้างและความสูงไม่เกิน 2.5 ซม. ไม่บังคับยืดเป็นรูปสี่เหลี่ยม
- เว้นหลังคำ “ที่ / วันที่ / เรื่อง / เรียน” เท่ากันครึ่งแท็บ (0.635 ซม. หรือ 18 pt) โดยคำทั้งสี่ยังเริ่มชิดขอบซ้ายเดิม ช่องว่างคงอยู่หลังแก้ข้อความแล้วกดจัดหน้าใหม่หรือดาวน์โหลด
- บรรทัด “ที่” และ “วันที่” ในหนังสือเหลือเพียงคำ ไม่เติมจุด เลขที่ หรือวันที่จากชีต เพื่อออกข้อมูลในระบบภายหลัง
- ย่อหน้า “ตามที่”, “บัดนี้” และ “จึงเรียนมาเพื่อ” เยื้องบรรทัดแรก 2 แท็บ โดยใช้แท็บมาตรฐานแท็บละ 1.27 ซม. รวม 2.54 ซม. จากขอบเนื้อหาซ้าย และจัดชิดซ้ายขวา (justify) บรรทัดสุดท้ายชิดซ้ายตามรูปแบบย่อหน้าปกติ
- หน้าหนังสือยังเป็น Letter ตาม Google Doc ต้นแบบ ส่วนแบบฟอร์มเดิมเป็น A4
- ตัวอย่างหนังสือหน้าแรกใช้ CSS ชุดเดียวกับ PDF ทั้งขนาดกระดาษ ฟอนต์ ระยะขอบ โลโก้ และการจัดข้อความ บนหน้าจอแคบเลื่อนซ้ายขวาได้โดยไม่ย่อขนาดกระดาษ
- หนังสือใหม่แสดงงวดเป็นเลขหน้าทับ เช่น 3/12 เป็น 3 ทุกตำแหน่ง ส่วนแบบฟอร์มเดิมยังคง 3/12
- หัวเรื่องใช้ชื่อจากแถวเดียวกัน ตัดเฉพาะเลขลำดับหน้าชื่อ เช่น “1. งาน...” เป็น “งาน...” และไม่เติมคำรวม “โครงการ/งาน”
- ย่อหน้าแรกใช้ “ตามที่ บริษัท [ชื่อบริษัท] ได้มีหนังสือเลขที่ ... ลงวันที่ ...” โดยไม่เติม “บริษัท” ซ้ำหากชื่อเริ่มด้วยคำนี้อยู่แล้ว

## ชื่อหน่วยงาน
- ASD, MLC, SVD → งานบริหารและพัฒนาระบบ
- DMP → งานออกแบบและผังแม่บท
- UBS → งานสาธารณูปโภคและระบบอาคาร
- TAS → งานจราจรและความปลอดภัย
- LSE → งานภูมิทัศน์และสิ่งแวดล้อม
- PMH → งานบริหารอาคารมหิดลสิทธาคาร
- SUD → งานพัฒนาเพื่อความยั่งยืน

รองรับช่องว่างรอบรหัสและตัวพิมพ์เล็ก/ใหญ่ ชื่อเต็มหรือรหัสที่ไม่รู้จักจะแสดงค่าต้นฉบับ ไม่เดาชื่อ และไม่แทนรหัสในช่องอื่น เช่น สถานที่หรือชื่อโครงการ

งวดงานยังใช้ P ตามต้นแบบ ไม่สลับไปใช้ BB อัตโนมัติ ส่วนรายชื่อผู้ลงนามปรับตามคำขอล่าสุดให้ใช้ประธาน หัวหน้า และผู้ควบคุมงานจริง ไม่ใช้ C “ชื่อผู้กรอกข้อมูล” แทน

ช่องที่ไม่มีข้อมูล เช่น เบอร์ต่อ เลขที่หนังสือบริษัท วันที่บนหนังสือ หรือข้อมูลสัญญา จะเว้นจุดไว้ และหน้าตัวอย่างแจ้งชื่อช่องที่ขาด ไม่ใช้เลขสัญญาแทนเลขที่หนังสือ และไม่ใช้วันส่งงานจริงหรือวันอื่นแทนวันที่บนหนังสือ ส่วน “ที่ / วันที่” ด้านบนไม่ถือเป็นข้อมูลขาด เพราะตั้งใจเว้นไว้

อ่านคอลัมน์ใหม่ตามชื่อหัว ไม่กำหนดว่าเป็น BD หรือ BE จึงยังอ่านถูกเมื่อมีคอลัมน์อื่นต่อท้าย โปรแกรมยังรองรับชื่อเดิม “เลขที่หนังสือส่งมอบงาน” หรือ “เลขที่หนังสือบริษัท” และเบอร์ “เบอร์โทรภายใน” หรือ “เบอร์ต่อ”

วันที่ภาษาไทยจากชีตจะแสดงตามค่าต้นทาง ไม่บวก พ.ศ. ซ้ำ และไม่เดาแก้ปีที่ผิดปกติ เช่น 3112 หากพบควรตรวจต้นทางก่อนออกเอกสาร วันที่ ISO จะแปลงเป็นวันที่ภาษาไทย เช่น 2026-11-09 เป็น 9 พฤศจิกายน 2569

ข้อความแนะนำให้ตรวจรับใช้เฉพาะสถานะ “แล้วเสร็จ เป็นไปตามเงื่อนไขของสัญญา” สถานะไม่แล้วเสร็จหรือไม่ชัดเจนจะแสดงสถานะตามข้อมูลและเว้นผลการพิจารณา ไม่สรุปว่าตรวจรับได้

## สำนวนหนังสือ
ปรับทั้งสามย่อหน้าให้เชื่อมความลื่นขึ้น โดยคงเลขที่หนังสือ วันที่ งวดงาน สัญญา และความหมายเดิม คงเงื่อนไขผลตรวจรับเดิม: ข้อมูลสถานะไม่ชัดเจนหรือยังไม่แล้วเสร็จจะไม่ถูกเปลี่ยนเป็นผลอนุมัติให้ตรวจรับ

## คำนำหน้าชื่อ
- ชื่อในวงเล็บของหนังสือใหม่และส่วนลงนามเติมคำนำหน้าจากฐานบุคลากรที่ตรวจยืนยัน 169 ชื่อ เมื่อวันที่ 10 พฤศจิกายน 2569
- ใช้ “ผศ.ดร.อิทธิโชติ จักรไพวงศ์” ตามคำสั่งเฉพาะของผู้ใช้
- ชื่อที่มีคำนำหน้าอยู่แล้วจะไม่เติมซ้ำ และไม่เปลี่ยนคำนำหน้าที่กรอกไว้ ยกเว้นบุคคลที่ผู้ใช้กำหนดข้างต้น
- ไม่เดาคำนำหน้าจากชื่อ เพศ หรือชื่อตำแหน่ง บุคคลที่ไม่มีในฐานและยังไม่ใส่คำนำหน้าจะแสดงชื่อต้นทาง พร้อมแจ้งให้ตรวจในหน้าตัวอย่าง
- ฐานในไฟล์เป็นข้อมูลที่ตรวจ ณ วันที่ระบุ ไม่ได้เชื่อมฐานบุคลากรแบบสด และไม่แก้ชื่อในชีตหรือแบบฟอร์มเดิม

## รายชื่อและเลขหน้า
- ประธานอยู่กลางด้านบน จากนั้นเรียงรายชื่อเป็นคู่ซ้าย–ขวาต่อเนื่อง: หัวหน้าซ้าย/ผู้ควบคุมคนที่ 1 ขวา แล้วผู้ควบคุมคนที่ 2 ซ้าย/คนที่ 3 ขวา และต่อไปตามลำดับ
- หน้าแรกวางประธานและคู่รายชื่อแรกไว้ด้วยกัน รวม 3 ลายเซ็น ลดเฉพาะพื้นที่ว่างตามความยาวเนื้อหา โดยยังมีช่องเขียนลายเซ็น 20–40 pt เหนือชื่อทุกคน และไม่เปลี่ยนขนาดฟอนต์
- หากมีหัวหน้าคนเดียวจะแสดงครั้งเดียว ไม่ทำชื่อซ้ำเพื่อเติมคอลัมน์ซ้าย
- ไม่ลบรายชื่อที่ซ้ำกันในข้อมูลต้นทางโดยเดา และไม่ผสมข้อมูลจากหลายแถว
- รายชื่อถัดจาก 3 คนแรกอยู่หน้าที่ 2 ทั้งหมด โดยรักษาคู่ซ้าย–ขวาและลำดับเดิม หากข้อความหรือรายชื่อมากเกินขนาดกระดาษแม้ลดช่องว่างแล้ว โปรแกรมแจ้งให้ตรวจข้อมูลแทนการตัดชื่อ ซ้อนข้อความ หรือย้ายไปหน้าที่ 3 โดยไม่แจ้ง
- Footer ใช้รหัสเอกสาร ฉบับ และวันที่บังคับใช้เหมือนแบบฟอร์มเก่า อยู่เหนือขอบล่าง 5 มม. และชิดขวา 10 มม. ตามคำขอล่าสุด โดยคงพื้นที่เนื้อหาและลายเซ็นเดิม
- หน้าที่ 2 ของ PDF มี “-2-” กึ่งกลางแนวนอน โดยห่างขอบบน 2 ซม. แม้หน้าที่ 2 เป็นส่วนแบบฟอร์มเดิม โดยไม่ชนเนื้อหา และยังคง footer ด้านล่าง
- เลขหน้ารันตามลำดับ PDF ทั้งไฟล์ เริ่มหนังสือหน้า 1 รวมหน้ารายชื่อที่ต่อ แล้วจึงต่อแบบฟอร์มเก่า ไม่เริ่มเลข 1 ซ้ำ

## จำนวนหน้า
เป็นสองส่วนเอกสารในไฟล์เดียว ไม่ได้บังคับรวมสองหน้ากระดาษ หนังสือมีหน้าแรกสำหรับเนื้อหาและ 3 ลายเซ็น หากมีรายชื่อเพิ่มเติมจะรวมไว้หน้าที่ 2 ส่วนแบบฟอร์มเดิมแบ่งหลายหน้าตามข้อมูลด้วยขอบใหม่และฟอนต์เดิม โดยไม่ตัดข้อมูลทิ้ง ตัวอย่างรายการ OPPE01F0801-58 ล่าสุดมีหนังสือ 2 หน้าและแบบฟอร์มเดิม 4 หน้า รวม 6 หน้า
